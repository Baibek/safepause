# SafePause Call Guard — проверка на телефоне / телефонда тексеру

Проверки, которые нельзя сделать в облачной сборке (нет эмулятора и устройства).
Отметьте каждую: ✅ работает / ❌ не работает (+ что видно на экране). Запишите модель телефона и версию Android.

Телефон: ____________ · Android: ____ · Дата: ________

| # | Шаг | Ожидаемый результат | Итог |
|---|---|---|---|
| 1 | Установить `safepause-guard.apk` (разрешить установку из этого источника) | Приложение открывается на экране «Настройка SafePause» | |
| 2 | Дать «Микрофон», «Состояние звонка», «Уведомления» | Точки становятся зелёными | |
| 3 | «Специальные возможности» → SafePause → включить. Если переключатель серый (Android 13+): Настройки → Приложения → SafePause → ⋮ → «Разрешить ограниченные настройки», затем снова | Точка зелёная | |
| 4 | «Скачать (~90 МБ)» на Wi-Fi | Обе модели «Готово» | |
| 5 | Настройки → «Тест микрофона» → «Probe 10 s», говорить рядом с телефоном | Полоса двигается, внизу появляется текст сказанного | |
| 6 | Позвонить на телефон с другого номера, **включить громкую связь**, нажать пузырь «SafePause: слушать?», второй человек говорит | Появляется полоса с текстом его слов | |
| 7 | Повторить 6, но без громкой связи | Подсказка «Включите громкую связь» | |
| 8 | Во время звонка второй человек читает сценарий `s01-safe-account-ru` из `detector/src/test/resources/eval/calls.json` | Красная карточка «Очень похоже на мошенника», вибрация, причины | |
| 9 | Второй человек читает обычный звонок `n01-bank-reminder-ru` | Карточка не становится красной | |
| 10 | Повторить 8 на казахском (`s02-safe-account-kk`) | Красная карточка | |
| 11 | Положить трубку | Уведомление «Итог звонка»; по нажатию — экран с причинами и текстом | |
| 12 | Звонок WhatsApp (аудио) на громкой связи, нажать пузырь, повторить 8 | Красная карточка | |
| 13 | Видеозвонок WhatsApp → «Проверить лицо» → разрешить запись экрана → выполнить 4 подсказки с человеком на другой стороне | Результат «Признаков подменённого лица не найдено». Если результат «Не удалось снять экран» — WhatsApp блокирует запись на этом телефоне | |
| 14 | То же, но человек не поворачивает голову | «Отказался от проверки» | |
| 14a | Видеозвонок WhatsApp → «Проверить вручную» → пройти 4 подсказки кнопкой «Далее» → ответить на 4 вопроса | Итог с признаками; работает и там, где WhatsApp запрещает запись экрана | |
| 15 | Главный экран → «Проверить на примере звонка» | Телефон читает сценарий вслух, карточка становится красной | |
| 16 | Режим полёта, повторить 15 | Предупреждение всё равно появляется (работает без интернета) | |
| 17 | Настройки → ввести ключ Claude API, повторить 15 | Под причинами появляются пояснения от Claude | |
| 17a | Дать «Состояние звонка» уже после включения спецвозможностей, затем позвонить | Пузырь всё равно появляется | |
| 17b | Второй человек говорит с паузой: «Никому не сообщайте… код из СМС» (как банк) | Карточка не красная | |
| 18 | Настройки → имя + номер доверенного человека, разрешить SMS, повторить 15 | На номер приходит SMS с именем и временем, без текста разговора | |

Если шаг 6 не работает (полоса не двигается, или карточка «Микрофон молчит»), пришлите модель телефона —
некоторые производители блокируют микрофон во время звонка для всех приложений. Тогда для демо
используйте шаги 12 (WhatsApp) и 15 (пример звонка).
