# SafePause Call Guard (Android)

Слушает телефонный звонок или звонок WhatsApp **на самом телефоне**, узнаёт сценарий мошенника
(«служба безопасности банка», «безопасный счёт», «код из SMS», AnyDesk…) на казахском и русском и
сразу показывает поверх экрана звонка красное предупреждение. Для видеозвонков WhatsApp есть
проверка лица по подсказкам.

## Как это работает

```
микрофон (громкая связь) ─▶ Vosk kk + Vosk ru (офлайн) ─▶ правила shared/call_rules.json ─▶ уровень риска ─▶ окно поверх звонка
                                                               └─▶ Claude (по желанию, только текст) ─ поднимает уровень максимум на 1 шаг
видеозвонок ─▶ запись экрана (с согласия) ─▶ ML Kit (лицо, поворот) + Claude vision (6–8 кадров) ─▶ список признаков
```

- **Детектор** (`detector/`, чистый Kotlin): 4 стадии сценария — *представился* (банк, полиция, госорган,
  родственник), *угроза/спешка*, *просьба* (перевод, код, AnyDesk), *изоляция* («никому не говорите»).
  Одна стадия — низкий риск; *просьба* + любая другая или три стадии — высокий; «безопасный счёт», код из SMS,
  программа удалённого доступа — высокий сразу. Предупреждения банка («никому не сообщайте код») не считаются.
- **Claude** может только поднять уровень на один шаг и никогда не понижает его, поэтому красное
  предупреждение всегда опирается хотя бы на одно правило. Без ключа и без интернета всё работает на правилах.

## Приватность

- Слушает только после нажатия «слушать?» в этом звонке.
- Звук не покидает телефон. В Claude уходит только текст (если ключ задан), а при проверке лица — 6–8 кадров.
- Текст разговора по умолчанию не сохраняется; хранится только время, уровень и причины.
- SMS доверенному человеку содержит имя, время и номер — не содержание разговора.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Микрофон | слышать собеседника через громкую связь |
| Состояние звонка | знать начало и конец звонка (номер не читается) |
| Специальные возможности | Android даёт микрофон во время звонка только таким приложениям; распознавание звонков WhatsApp; окно поверх звонка |
| Уведомления | значок прослушивания и итог звонка |
| SMS (по желанию) | сообщение доверенному человеку |
| Запись экрана (каждый раз) | проверка лица в видеозвонке |

## Сборка

```bash
./tools/setup-sdk.sh                     # Android SDK (один раз)
./gradlew :detector:test                 # детектор + оценка
./gradlew :app:testDebugUnitTest         # логика приложения
./gradlew :app:assembleDebug             # APK: app/build/outputs/apk/debug/app-debug.apk
```

Если Maven Central отвечает `429 Too Many Requests`, запустите `./tools/fetch-missing.sh <лог сборки>` и
повторите сборку: скрипт по одному скачивает недостающие файлы в `~/.m2`.

Проверка на телефоне: [DEVICE_TEST.md](DEVICE_TEST.md).

## Ограничения

- **Нет iPhone**: iOS не даёт приложениям доступ к звуку звонка.
- **Нужна громкая связь**: голос собеседника слышен только через микрофон.
- Некоторые производители (часто Xiaomi, иногда Samsung) блокируют микрофон во время звонка для всех
  приложений — тогда приложение покажет «Микрофон молчит». Проверьте шагом 6 в DEVICE_TEST.
- **Нет автоматического распознавания синтезированного голоса**: готовую модель нельзя было скачать в среде
  сборки. Приложение оценивает, *что* говорят, — это ловит и обычного мошенника-человека.
- Проверка лица — не вердикт «дипфейк на N %», а список замеченных признаков.
- Записи хранятся в JSON-файле, а не в Room (в спецификации — Room): так проще, и десятков записей это не замедляет.
- Не проверено в этой среде (нет эмулятора): работа на устройстве, живой вызов Claude, запись экрана.
- APK весит ~125 МБ: почти всё — официальный Anthropic Java SDK (~45 МБ jar). Сжатие R8 его уменьшило бы,
  но без проверки на телефоне оно может сломать распознавание речи (JNA) — для демо выбрана надёжная, несжатая сборка.
- Установка только через APK: использование спецвозможностей и SMS не пройдёт модерацию Google Play в таком виде.
