# Senim — аудармаға дейін алаяқтықты анықтау

FINTECH CASE үшін MVP. Клиент «банктің қауіпсіздік қызметі» деген алаяқтың айтуымен ақшаны **өзі**
аударады, сондықтан әдеттегі антифрод оны көрмейді. Senim аударманы бұғаттамайды — тәуекел жоғары
болса, оны бір сәтке тоқтатып, клиентпен қысқа диалог жүргізеді.

**Демо:** https://baibek.github.io/safepause/ · **Кейс талаптары мен нәтижелер:** [docs/CASE_MAP.md](docs/CASE_MAP.md) ·
**BCC-ке енгізу:** [docs/BCC_INTEGRATION.md](docs/BCC_INTEGRATION.md)

## Басқалардан айырмашылығы

Senim алаяқты **қоңырау кезінде естиді**. Сөйлеу құрылғының ішінде мәтінге айналады (Vosk, қазақ және орыс,
интернетсіз), ал детектор алаяқ сценарийінің сатыларын (таныстыру → қорқыту → сұрау → оқшаулау) санайды.
Қоңырау алаяқ деп танылса, келесі 60 минутта банк қосымшасындағы кез келген аударым тексеруге түседі.

## Не шынайы, не симуляция

| Бөлік | Демода | Банкте |
|---|---|---|
| Сөйлеуді тану, сценарий детекторы | Шынайы: Android-та және сайтта (браузердегі Vosk) | Сол модуль BCC қосымшасының ішінде |
| Аударым скорингі, түсіндірме, диалог, кідірту | Шынайы логика, синтетикалық деректер | BCC тарихымен қайта үйрету |
| Дроп-желі графы | Шынайы алгоритм, синтетикалық транзакциялар | Антифрод растаған шоттар |
| Демо-қоңыраулар | Piper дауыстарымен жазылған 100 диалог | — |
| Қамқоршыға хабар | Демо экранында | Push немесе SMS |

## Android қосымшасы: қоңырау кезіндегі қорғаныс

`android/` — нақты Android қосымшасы: қоңырауды (қарапайым және WhatsApp) динамик арқылы тыңдап,
сөйлеуді телефонның өзінде таниды (қазақ және орыс, интернетсіз) және алаяқтың сценарийі естілгенде
ескертеді. Толығырақ: [android/README.md](android/README.md).

## Не істейді

| Тарап | Мүмкіндік |
|---|---|
| Клиент | Әр аударманы нақты уақытта бағалау → тәуекел жоғары болса AI-диалог (қазақша / орысша) → аударма **өтеді**, **кейінге қалады** немесе **тоқтатылады** |
| Клиент | Банктің растау қоңырауы: әдеттен тыс, күдікті немесе басқа банкке ірі аударымда банк роботы қоңырау шалып ескерту оқиды; клиент 1-ді басса аударым жіберіледі, 2-ні басса бұғатталады |
| Клиент | «Қамқоршы» режимі: қарт клиенттің ірі күдікті аудармасы туралы сенімді туысына хабар барады, ол растай не тоқтата алады |
| Клиент | Хабарлама тексеру: күдікті SMS / WhatsApp мәтінін қойса, алаяқтық белгілері қарапайым тілмен түсіндіріледі (LLM + ережелер) |
| Банк | Аналитик дашборды: аудармалар легі, әр шешімнің түсіндірмесі (SHAP үлестері), клиентпен диалог |
| Банк | Дроп-желілер графы: ақша кіріп, бірнеше минутта шығып кететін шоттар тізбегі |

Екі бөлік байланысты: графта дроп деп табылған шотқа аударма жасалса, клиент жағындағы тәуекел өседі.

## Іске қосу

```bash
./run.sh
```

Сосын браузерде `http://localhost:8000` ашыңыз. LLM мәтіндері үшін `ANTHROPIC_API_KEY` орнатыңыз;
кілт болмаса, диалог дайын үлгі мәтіндермен жұмыс істейді (шешім логикасы өзгермейді).

Әзірлеу режимі: `cd backend && uvicorn main:app --reload --port 8000` және `cd frontend && npm run dev`.

### Виртуалды нұсқа (серверсіз)

```bash
cd frontend && npm run build:virtual
```

`frontend/dist-virtual/` ішінде бір бет пен `app.js` шығады: модель (XGBoost ағаштары + дәл TreeSHAP),
диалог логикасы мен граф толығымен браузерде жұмыс істейді. `node src/virtual/check.mjs` JS-порттың
XGBoost-пен сәйкестігін тексереді. Модельді қайта үйреткен соң `python backend/export_virtual.py` іске қосыңыз.

## Демо сценарийі (2 минут)

1. **«Банк қауіпсіздік қызметі» қоңырау шалды** → «Аудару». Модель 100% тәуекел береді, диалог басталады.
   «Иә» деп жауап берсеңіз — аударма бірден тоқтатылады, қамқоршыға хабар барады.
2. Сол сценарийде бәріне «дұрыс» жауап беріңіз (алаяқ үйретіп қойған жағдай) — аударма бәрібір
   60 минутқа кейінге қалады, қамқоршы оны тоқтата алады.
3. **Қызына әдеттегі аударма** — ешқандай кідіріссіз өтеді.
4. **Аналитик дашборды** — осы аудармалар лекте «демо» белгісімен тұр; алушы шот графтағы №1 желіде.

## Қалай жұмыс істейді

- `backend/train.py` — деректерді генерациялайды және XGBoost моделін үйретеді. 14 белгі: сома,
  әдеттегі сомаға қатынасы, жаңа алушы, уақыт, телефон қоңырауы, бейтаныс нөмір, қашықтан басқару
  қолданбасы, әрекет қарқыны, алушы шотының жасы мен дроп-баллы және т.б.
- `backend/main.py` — FastAPI. Тәуекел < 25% → өтеді; одан жоғары → диалог. Шешімді ережелер қабылдайды,
  LLM тек мәтінді қарапайым тілмен жазады және еркін жауапты «иә / жоқ» деп түсінеді.
- `backend/graph.py` — NetworkX. Шот белгілері: транзит үлесі, ақшаның шотта тұру уақыты, жіберушілер
  саны, шот жасы → дроп-балл → байланысқан компоненттер = желілер.
- `backend/llm.py` — Claude API (`claude-opus-5-5`, `SAFEPAUSE_LLM_MODEL` арқылы өзгертуге болады).
- `shared/message_rules.json` — хабарлама тексерудің ережелері; backend пен браузер бір файлды қолданады.
  LLM үкімі ережелер тапқаннан төмен түсе алмайды.
- `frontend/src/virtual/` — backend-тің браузердегі порты (виртуалды нұсқа үшін).
- `frontend/` — React + Vite, граф үшін vis-network.

## Шектеулер (ашық айтамыз)

- **Деректер синтетикалық.** PaySim / IEEE-CIS датасеттерінде қоңырау мен құрылғы белгілері жоқ, сондықтан
  олар сценарийге сай үлестірімдермен генерацияланды. ROC-AUC 0.96 — модельдің нақты сапасы емес,
  пайплайнның жұмыс істейтінінің дәлелі. Графтағы 100% дәлдік те сол себепті.
- Қоңырау мен AnyDesk белгілері демода қолмен қосылады; нақты қосымшада оларды мобильді SDK жинайды.
- Сақтау жадта (in-memory), авторизация жоқ. Кейінге қалдыру таймері көрсетіледі, бірақ іс жүзінде санамайды.
- Граф бөлігі — графтық белгілер + эвристика; GNN келесі қадам.
