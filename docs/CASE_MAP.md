# Кейс талаптары → Senim

FINTECH CASE, Банк ЦентрКредит: «Инновации в банкинге и кибербезопасности». Әр бағыт бойынша не жасалғаны және
кодтың қай жерде екені. Барлық деректер синтетикалық; нақты сапаны BCC деректерімен пилот көрсетеді.

| Кейс бағыты | Senim-де | Код |
|---|---|---|
| Алаяқтық операцияларды анықтау | Аударым XGBoost моделімен бағаланады, әр белгінің үлесі (TreeSHAP) көрсетіледі; дроп-шотқа аударым тәуекелді көтереді | `backend/train.py`, `backend/main.py`, `frontend/src/virtual/shap.js` |
| Әлеуметтік инженерияны тану | Қоңырау кезінде сөйлеу телефонның/браузердің ішінде танылады (Vosk, қазақ және орыс), детектор алаяқ сценарийінің 4 сатысын іздейді | `android/`, `shared/call_rules.json`, `frontend/src/call/` |
| Клиентті қорғау | Аударым бұғатталмайды, кідіртіледі: бас тарту / 60 минутқа қалдыру / AI сұрақтарынан кейін жалғастыру; «Қамқоршы» туысқа хабар береді | `frontend/src/phone/screens.jsx`, `backend/main.py` |
| Әдеттен тыс аударымды растау | Сома әдеттегіден 3 есе көп, басқа банкке 50 000 ₸-ден асатын немесе күдікті аударымда банк роботы клиентке қоңырау шалып, алаяқтық туралы ескерту оқиды: 1 — өзім жасап жатырмын → аударым жіберіледі; 2 — мен емес → бұғатталады; жауап жоқ → 60 минутқа кейінге қалады | `shared/verify_call.json`, `POST /api/verify/respond`, `frontend/src/phone/VerifyCall.jsx` |
| Киберқауіпсіздік: SMS-кодтан бас тарту | Passkey (WebAuthn): клиент операцияның деректеріне қол қояды | `backend/webauthn.py`, `frontend/src/phone/passkey.js` |
| Киберқауіпсіздік: құрылғы | Android RASP: root, эмулятор, қашықтан басқару, overlay | `android/app/src/main/java/kz/safepause/guard/rasp/` |
| Киберқауіпсіздік: сервер | Рөлдер, CSRF, rate limit, логта маскалау | `shared/access_policy.json`, `backend/security.py` |
| Ұлттық жүйемен байланыс | Антифрод-орталыққа есеп (демо-формат, жеке деректерсіз) | `POST /api/analyst/report` |
| Мінез-құлық биометриясы | Теру ырғағы клиенттің әдеттегісімен салыстырылады, қосымшадан шығу, телефонның бұрышы, түзетулер | `frontend/src/transfer/TransferSection.jsx`, `shared/risk_policy.json` |
| Кіріс граф-аналитикасы | Көп жіберуші + жылдам шығару → граф дропперді автоматты белгілейді | `backend/saqshy.py` (`flag_from_graph`), `auto_drop` |
| Банкаралық федеративтік оқыту | FedAvg демо: деректер банктен шықпайды, тек салмақтар | `frontend/src/virtual/federated.js` |
| Деректерді қорғау | Дыбыс пен әңгіме мәтіні құрылғыдан шықпайды; банкке тек `scam_call_minutes` саны барады | `android/.../sdk/SafePauseSdk.kt`, `docs/BCC_INTEGRATION.md` |
| Банк үшін жаңа сервис | Антифрод аналитигінің қосымшасы: кезек, түсіндірме, дроп-желі картасы | `frontend/src/phone/AnalystApp.jsx`, `backend/graph.py` |
| Енгізу | Мобильді қосымшаға модуль + аударым API-ына бір өріс; API келісімшарты мен пилот жоспары | `docs/BCC_INTEGRATION.md` |
